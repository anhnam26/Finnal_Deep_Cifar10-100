LUỒNG CONVOLUTION VÀ FORWARD CHI TIẾT - COMPACTMIX-L
==================================================
Dùng để đọc và tự vẽ lại đúng model đã train CIFAR-10 / CIFAR-100.
Nguồn: src/models.py và cấu hình experiment thực tế.

CHÚ Ý VỀ ACTIVATION
------------------
Model đang dùng SiLU (còn gọi là Swish) và Sigmoid trong SE.
Không có ReLU hoặc GELU trong model CompactMix-L của hai run này.
Chuỗi nonlinearity='relu' trong initialize() chỉ là tùy chọn khởi tạo Kaiming,
không tạo thêm một lớp ReLU trong forward.
ReLU ở PreActBlock/ResidualNet và GELU ở ConvNeXt thuộc model khác trong file.

Trong bản vẽ hãy ghi: [BatchNorm] -> [SiLU], không đổi thành [Conv -> ReLU]
nếu thứ tự/thành phần này không có trong code.

MỤC LỤC
-------
1. Cách đọc kích thước và thông số.
2. Luồng toàn mạng, đã liệt kê đủ 13 MixBlock.
3. Sơ đồ một MixBlock với hai nhánh và residual.
4. Sơ đồ SE và các phép toán không tạo nn.Module.
5. Bung từng lớp của cả 13 block + stem + transitions + head.
6. Bảng tham số từng block và tổng hợp.
7. Code forward thực tế.
8. Công thức Conv, BN, SiLU, attention và hướng dẫn vẽ.

1. CÁCH ĐỌC
===========
Tensor dùng thứ tự [N, C, H, W]:
  N: batch size (khi train thường 128; batch cuối có thể nhỏ hơn).
  C: số kênh; H: chiều cao; W: chiều rộng.
  Khi đã flatten: [N, D]. Khi ra logits: [N, K].
  K=10 cho CIFAR-10; K=100 cho CIFAR-100.

Ký hiệu:
  k = kernel_size, s = stride, p = padding, d = dilation, g = groups.
  P = số tham số học được; P=0 nghĩa là không có trọng số học.
  w = kích thước tensor weight, thứ tự Conv2d là [Cout, Cin/g, kh, kw].
  bias=False: không có vector bias; bias=True: có bias kích thước Cout.
  BN có gamma/beta học được; running_mean/running_var là buffer, không tính P.

Mũi tên "->" là nối tiếp.
Tách nhánh local/context là hai luồng cùng nhận dữ liệu từ chunk;
không vẽ DW3 -> DW5 nối tiếp nhau.
[ADD] là cộng element-wise. [MUL] là nhân element-wise có broadcast.
[CAT dim=1] nối theo số kênh, không cộng hai nhánh.

Chỉ số trong source:
  Stage 1 = stages.0; Stage 2 = stages.1; Stage 3 = stages.2.
  Stage 2/3 có 4 layer transition ở đầu, nên MixBlock đầu nằm ở index 4.
  Hai model có cùng 260 lớp lá đầu; lớp lá 261 (Linear) khác số nhãn.
  File này liệt kê tất cả lớp lá và chèn thêm chunk/cat/MUL/ADD/flatten,
  là những phép toán có trong forward nhưng không xuất hiện như nn.Module.

Đầu vào forward là tensor đã ToTensor và Normalize. Random crop, flip,
AutoAugment, Mixup/CutMix nằm trong data/train pipeline, không nằm trong model.

  [BN256] -> [SiLU] -> [Global AvgPool 1x1] -> [Flatten]

Argmax được thực hiện khi đánh giá, nằm ngoài CompactMixNet.forward().
Softmax cũng không có trong forward. Nếu cần xác suất để hiển thị:
  probabilities = softmax(logits, dim=1).
Hai Linear 256->10 và 256->100 là hai lựa chọn head cho hai model riêng,
không phải hai nhánh chạy đồng thời trong cùng một model.

3. SƠ ĐỒ CHI TIẾT MỘT MIXBLOCK
=============================
Mỗi block nhận x=[N,C,H,W] và trả y=[N,C,H,W]. Không giảm H,W trong block.
expanded=2*C; mỗi nhánh sau chunk có C kênh; residual_scale=1.

                         x [N,C,H,W]
                           |
          +----------------+------------------------------------+
          |                                                     |
          | MAIN PATH                                           | SKIP
          v                                                     | identity
      [BN(C)]                                                   | giữ x gốc
          |                                                     |
        [SiLU]                                                  |
          |                                                     |
      [Conv1x1 C->2C, g=1, bias=False]                           |
          |                                                     |
      [BN(2C)]                                                  |
          |                                                     |
        [SiLU]                                                  |
          |                                                     |
      [CHUNK 2, dim=1]                                          |
          |                    |                                |
       a[N,C,H,W]          b[N,C,H,W]                            |
          |                    |                                |
      [DW Conv3x3]        [DW Conv5x5]                            |
       s=1,p=1,g=C         s=1,p=2,g=C                           |
       bias=False          bias=False                           |
          |                    |                                |
          +----------+---------+                                |
                     |                                          |
              [CAT dim=1]                                       |
               [N,2C,H,W]                                        |
                     |                                          |
                 [BN(2C)]                                       |
                     |                                          |
                   [SiLU]                                       |
                     |                                          |
      [Grouped Conv3x3 2C->2C, g=8, s=1,p=1,bias=False]          |
                     |                                          |
                 [BN(2C)]                                       |
                     |                                          |
                   [SiLU]                                       |
                     |                                          |
              [SE ChannelGate]                                  |
        (chi tiết GAP/Conv/SiLU/Conv/Sigmoid/MUL ở mục 4)           |
                     |                                          |
       [Conv1x1 2C->C, g=1, s=1,p=0,bias=False]                  |
                     |                                          |
                 [DropPath]                                     |
                     |                                          |
                     +---------------->[ADD: x + residual]<-----+
                                           |
                                           y [N,C,H,W]

Không có BN hoặc activation sau Conv1x1 projection và trước DropPath.
Không có activation sau ADD trong chính block. Khi sang block kế tiếp,
BN rồi SiLU ở pre của block kế tiếp sẽ xử lý tensor vừa nhận.
DW3 và DW5 không có activation/BN riêng ở ngay sau từng nhánh; cả hai
được CAT trước rồi mới đi qua BN và SiLU của self.mix.

4. SE CHANNELGATE VÀ PHÉP TOÁN KHÔNG CÓ WEIGHT
=============================================
SE nhận f=[N,2C,H,W]; d_se=max(8, floor(2C/16)).

             f [N,2C,H,W]
                |
       +--------+---------------------------------------------------+
       |                                                            |
       v                                                            |
  [AdaptiveAvgPool2d(1)]                                             |
       | z=[N,2C,1,1]                                               |
  [Conv1x1 2C->d_se, bias=True]                                      |
       | [N,d_se,1,1]                                               |
     [SiLU]                                                         |
       |                                                            |
  [Conv1x1 d_se->2C, bias=True]                                      |
       | [N,2C,1,1]                                                 |
    [Sigmoid]                                                       |
       | g=[N,2C,1,1]                                               |
       +------------------------->[MUL: f * g]<---------------------+
                                       |
                                  [N,2C,H,W]

Gate g được broadcast trên H,W, mỗi kênh có một hệ số attention.
Đường identity của SE là f để nhân; khác đường skip x của MixBlock để cộng.
SE không dùng ReLU trong cấu hình này; activation bên trong là SiLU.

Thông số cụ thể:
  Stage 1: SE nhận 80 kênh; 80 -> 8 -> 80; hai Conv có 648 và 720 P.
  Stage 2: SE nhận 224 kênh; 224 -> 14 -> 224; có 3.150 và 3.360 P.
  Stage 3: SE nhận 512 kênh; 512 -> 32 -> 512; có 16.416 và 16.896 P.

Chunk, cat, MUL attention, ADD residual và flatten có P=0.
DropPath có P=0. Train: mask [N,1,1,1], keep=1-p, r'=r*mask/keep.
Eval: r'=r. DropPath chỉ tác động nhánh residual, không bỏ đường skip x.
Block đầu p=0; block cuối p=0.1. Head Dropout p=0 nên luôn identity.

5. BUNG TỪNG LỚP THEO ĐÚNG LỆNH FORWARD

Các dòng [OP 001]...[OP 261] là 261 lớp lá thực sự được gọi.
Các dòng [FUNC ...] được chèn tại đúng vị trí chunk/cat/MUL/ADD/flatten.
Shape dưới đây dùng N để bạn vẽ cho mọi batch; đã kiểm tra CPU forward N=1.
P ghi trên mỗi OP; total block đã bao gồm mọi lớp bên trong SE.
Không cộng lại total block vào tổng các OP vì sẽ đếm trùng.

7. CODE FORWARD NGUYÊN BẢN
========================================

CompactMixNet.forward:
def forward(self, x):
        return self.head(self.stages(self.stem(x)))

MixBlock.forward:
def forward(self, x):
        a, b = self.pre(x).chunk(2, dim=1)
        residual = self.mix(torch.cat((self.local(a), self.context(b)), dim=1))
        if self.residual_scale != 1:
            residual = residual * self.residual_scale
        return x + self.drop(residual)

ChannelGate.forward:
def forward(self, x):
        pooled = self.pool(x)
        if self.kind == 'se':
            gate = self.gate(pooled)
        else:
            gate = self.sigmoid(self.gate(pooled.flatten(2).transpose(1, 2)))
            gate = gate.transpose(1, 2).unsqueeze(-1)
        return x * gate

GlobalPool.forward:
def forward(self, x):
        pooled = self.avg(x)
        if self.maximum is not None:
            pooled = (pooled + self.maximum(x)) * .5
        return pooled.flatten(1)

DropPath.forward:
def forward(self, x):
        if not self.training or not self.probability:
            return x
        keep = 1 - self.probability
        mask = torch.rand((x.shape[0], 1, 1, 1), device=x.device) < keep
        return x * mask.to(x.dtype) / keep

Đọc dòng return self.head(self.stages(self.stem(x))) từ trong ra ngoài:
  1) self.stem(x)   -> [N,40,32,32]
  2) self.stages(...) gọi stages.0, rồi stages.1, rồi stages.2
                   -> [N,256,8,8]
  3) self.head(...) -> [N,K]
  4) return logits

8. CÔNG THỨC VÀ CHECKLIST KHI TỰ VẼ
===================================
Conv2d:
  Hout = floor((Hin + 2*p - d*(k-1) - 1)/s + 1); tương tự cho W.
  P = Cout*(Cin/groups)*kh*kw + (Cout nếu bias=True).
  Dense Conv: groups=1, mỗi output channel kết nối tất cả input channels.
  Depthwise: groups=Cin=Cout; trong nhánh này mỗi kênh có một filter riêng.
  Grouped 3x3: groups=8; Conv1x1 dense trước/sau vẫn trộn toàn bộ kênh.
  Conv trong model mặc định d=1, padding_mode=zeros; chỉ các DW/grouped
  có padding không bằng 0 để giữ H,W. Stem cũng dùng p=1 để giữ 32x32.

BN(C):
  Affine=True, gamma[C] và beta[C] -> 2*C tham số học được.
  eps=1e-5; momentum=0.1; track_running_stats=True.
  Train dùng batch statistics và cập nhật running statistics.
  Eval dùng running_mean/running_var, không dùng thống kê batch mới.

SiLU:
  SiLU(x)=x*sigmoid(x); không có tham số học, giữ nguyên shape.
  nn.SiLU() ở đây có inplace=False.
  Sigmoid(x)=1/(1+exp(-x)); dùng ở cuối mạng gate SE.

Pooling:
  Transition dùng AvgPool2d(kernel_size=2, stride=2, padding=0,
    ceil_mode=False, count_include_pad=True).
  SE/head dùng AdaptiveAvgPool2d(output_size=1): trung bình H*W phần tử
    của từng kênh -> [N,C,1,1]; không làm thay đổi số kênh.
  GlobalPool.forward thực hiện GAP trước rồi flatten(start_dim=1).

Thứ tự để vẽ một block cho dễ:
  A. Vẽ x ở trên, giữ một đường skip dài đến nút ADD cuối.
  B. Vẽ riêng từng ô BN -> SiLU -> Conv1x1 -> BN -> SiLU.
  C. Vẽ nút CHUNK thành 2 nhánh DW3/DW5 cùng shape C,H,W.
  D. Hợp vào CAT dim=1, output có 2C kênh.
  E. Vẽ BN -> SiLU -> Grouped Conv3x3 -> BN -> SiLU.
  F. Vẽ SE thành một khung lớn; bên trong GAP -> Conv1 -> SiLU ->
     Conv2 -> Sigmoid; nối gate và feature gốc vào nút MUL.
  G. Vẽ projection Conv1x1 2C->C -> DropPath -> ADD với x.
  H. Ghi shape dưới mỗi ô; ghi k/s/p/g và bias trong mỗi ô Conv.
  I. Ghi xác suất DropPath riêng của đúng block, theo mục 2 hoặc mục 5.
  J. Vẽ đủ 2+3+8 block; chỉ transition đổi độ phân giải 32->16->8.
  K. Head ghi rõ BN256, SiLU, GAP, Flatten, Dropout(0), Linear256->K.

Điểm dễ vẽ sai cần tránh:
  - Ghi ReLU thay cho SiLU của model đang train.
  - Đổi hai nhánh DW3/DW5 thành hai Conv nối tiếp.
  - Đổi CAT thành ADD, làm mất việc tăng số kênh C+C=2C.
  - Nhân gate với x C kênh; thực tế SE nhân với feature 2C kênh.
  - Vẽ SE ở sau projection; thực tế SE đứng trước projection.
  - Quên bias của 2 Conv trong SE hoặc thêm bias vào stem/DW/group/projection.
  - Thêm activation sau ADD hoặc sau projection dù code không có.
  - Đưa Softmax/Argmax vào CompactMixNet.forward.
  - Tưởng EMA là một layer trong model. EMA chỉ là cách cập nhật trọng số,
    backbone/forward của raw và EMA hoàn toàn cùng kiến trúc.

SCOPE
=====
Mô tả trên chỉ dành cho CompactMix-L thực sự đã dùng cho hai dataset.
Không gộp ReLU của ResidualNet, GELU/LayerNorm của ConvNeXt hoặc biến thể ECA
vào kiến trúc này. Các nhánh if cho residual_scale khác 1, pooling avgmax,
stacked stem và attention khác SE không được kích hoạt trong hai cấu hình.
